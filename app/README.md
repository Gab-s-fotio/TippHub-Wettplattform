# MyDemo

# Projekt Starten

# 1. Node.js runterladen

  Von https://nodejs.org/ die aktuelle LTS-Version herunterladen und installieren.

# 2. Angular CLI installieren:
  Ordner egal, wird global installiert
  npm install -g @angular/cli 

# 3. Abhängigkeiten installieren:
  Im Projektordner: 
  npm install

# 4. Projekt starten:
Im Projektordner:
  ng serve
